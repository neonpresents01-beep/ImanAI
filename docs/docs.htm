🤖 ImanAILite

کتابخانه هوش مصنوعی سبک، بومی و بدون وابستگی برای پایتون

✅ نسخه ۱.۰ منتشر شد! ۳۰ تست موفق، پایدار روی 32-bit

✨ ویژگی‌ها

  • ✅ بدون وابستگی - فقط NumPy (و CuPy اختیاری برای GPU)
  • ✅ سبک - حجم ~۱۰ مگابایت
  • ✅ سازگار با 32-bit - روی ویندوز ۷ اجرا می‌شود
  • ✅ کامل - Dense, LSTM, CNN, Attention, Transformer
  • ✅ بومی - کد از صفر نوشته شده، کاملاً ایرانی

🚀 نصب سریع

pip install ImanAILite
💡 نکته: برای استفاده از GPU، CuPy را نصب کنید: 
pip install cupy-cuda11x

📖 مثال سریع

from ImanAILite import ImanAILite
import numpy as np

ai = ImanAILite()

# ایجاد مدل
model = ai.create_classifier("my_model", input_dim=10, num_classes=2)

# داده نمونه
X = np.random.randn(100, 10)
y = (np.sum(X, axis=1) > 0).astype(int)

# آموزش
ai.train("my_model", X, y, epochs=10, batch_size=16)

# پیش‌بینی
predictions = ai.predict("my_model", X[:5])
print(predictions)

🎯 لایه‌های موجود

  • Dense - لایه fully-connected
  • LSTM - حافظه بلندمدت
  • Conv2D - لایه کانولوشن
  • Attention - مکانیزم توجه
  • Dropout - جلوگیری از overfitting
  • BatchNorm - نرمال‌سازی دسته‌ای
  • Flatten - صاف کردن
  • Embedding - تبدیل کلمات به بردار
